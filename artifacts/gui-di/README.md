# HỘP GỬI ĐI — mọi thứ trong đây sắp rời khỏi máy

Bỏ vào đây thứ định gửi cho tuyến ngoài (ChatGPT, Claude web, đồng nghiệp), rồi chạy:

    node scripts/chon-tuyen.mjs --gui artifacts/gui-di

Chuông soi email · điện thoại · khoá API · và **ảnh chụp màn của route có vẽ dữ liệu cá nhân**
(suy ngược từ mã, vì máy không đọc được chữ trong ảnh).

thì app thật có gì nó chụp nấy. Chuông không có cờ bỏ qua: muốn gửi thì sửa lô gửi, không sửa chuông.
