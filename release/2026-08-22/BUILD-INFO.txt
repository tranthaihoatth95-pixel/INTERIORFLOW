Runtime model
-------------
The app spawns a local Next.js production server on 127.0.0.1:3777 (probes upward
if busy) and points a BrowserWindow at it. No dev server, no terminal required.
On startup it runs 'prisma db push' against a SQLite DB in userData; if that is
refused due to a data-loss warning it backs up dev.db (+wal/journal/shm) and
retries once with --accept-data-loss, then reports honestly if it still fails.
