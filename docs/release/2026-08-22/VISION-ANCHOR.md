# VISION ANCHOR — read before implementing anything (22/08/2026)

## What InteriorFlow is
A vertical creative operating system for professional interior/spatial design.
Its advantage is CONTINUITY: intent → context → source → object → transformation →
decision → revision → output → memory → Design DNA.

## Non-negotiable laws for this release
1. **NO-REBUILD.** LOOK INSIDE → MAP EXISTING → CLASSIFY → CONNECT → EXTEND → NEW.
   NEW requires negative evidence (searched where, nearest primitive, why reuse fails).
2. **One canonical owner per truth.** Never create a second Project/Site/Material truth.
3. **Local-first.** Deterministic core must work without cloud/AI/internet.
4. **AI proposes, human decides.** AI never silently mutates canonical truth.
   Standards checking is DETERMINISTIC MACHINE work, never AI.
5. **No fabricated data.** No fake counts, projects, providers, timestamps.
   If data is absent, change the composition — do not invent it.
6. **Real-app evidence beats tests for visual behavior.**
   screenshot > DOM > tests > source > mock.
7. **Neutral product.** No TTT or any studio brand hardcoded. Brand Kit is per-project.
8. **Preserve → repair → extend → evolve.** Never delete-and-rewrite for aesthetics.
