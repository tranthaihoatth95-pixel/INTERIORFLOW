10 · CẬP NHẬT VỀ SAU

Mọi ngày mới commit → chạy lại script grep để cập nhật:

bash
git log --format='%as' | sort -u | wc -l         # số ngày làm việc
git log --oneline | wc -l                         # tổng commit
git log --format='%s' | sed -E 's/^([a-z]+)./\1/' | sort | uniq -c    # loại commit
